# 📊 Supply Chain Operational Analysis (Excel)

## Project Overview
This project demonstrates advanced Excel capabilities by analyzing operational delivery metrics across the Juja and Ruaka zones. The objective is to evaluate dispatch volumes, monitor Service Level Agreement (SLA) compliance, and categorize customer satisfaction ratings.

## Technical Skills Demonstrated
* **Advanced Formulas:** Utilized `AVERAGEIF` and `SUMIF` to isolate specific zone performance metrics.
* **Logical Functions:** Applied nested `IF` statements to automatically categorize raw customer ratings into actionable tiers (Excellent, Acceptable, Review Needed).
* **Data Aggregation:** Built dynamic Pivot Tables with applied filtering to cross-tabulate dispatch volumes by product category and on-time status.

## Repository Contents
* `Excel supply-analysis.xlsx`: The complete workbook containing the untouched raw data, the formula-driven analysis tab, and the filtered Pivot Table summary.
